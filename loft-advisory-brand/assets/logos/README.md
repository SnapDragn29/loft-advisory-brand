# Approved logos

Use the four files in `png/`. `loft-advisory-*` is the full offset lockup; `loft-wordmark-*` is the LOFT-only responsive mark. Navy uses the approved supplied Ink Blue #2B4057; ivory is #F7F3EC. Each PNG is 3000 × 1400 with transparency and unchanged original margins.

The current heavier Bodoni Moda artwork is supplied as PNG only. SVG files in the archive belong to an earlier version; do not promote them into the current set. Obtain genuine SVG and editable masters from the finalized design source if needed. Do not trace, recreate, recolor, or wrap the PNG in an SVG.
