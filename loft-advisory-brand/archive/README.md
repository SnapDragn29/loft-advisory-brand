# Historical reference only

These files are superseded and must not guide current design or be served as current logos. They are retained unchanged for reference, not deleted.

- `initial-brand-system/`: original DESIGN.md, tokens.json, two PNG and two SVG logos from commit bb96f91. Earlier colors, Avenir/Raleway, and experimental copy are retired.
- `previous-brand-system/`: four earlier PNGs and their original manifest from commit 8d5d305. The historical manifest retains its original paths; it is a provenance record, not a current asset index.

Original uppercase/lowercase logo names collided on case-insensitive filesystems. Separate generation folders preserve all distinct source files safely. Current guidance is [BRAND_SYSTEM.md](../BRAND_SYSTEM.md).
