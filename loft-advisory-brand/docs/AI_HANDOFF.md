# AI Handoff

Read `../BRAND_SYSTEM.md` before generating a LOFT design.

For messaging, service structure, audience terminology, Blueprint phases, scope boundaries, and current LOFT positioning, also read:

`../MESSAGING_AND_SERVICE_ARCHITECTURE.md`

Use `../tokens/brand-tokens.json` for implementation values and `../assets/asset-manifest.json` for actual supplied assets.

Resolve all paths relative to the repository root unless a file explicitly says otherwise.

## Visual Rules

- Keep the layout neutral-led, with Ink Blue emphasis and sparse Aubergine details.
- Use Lora Regular for editorial personality and DM Sans Regular/Medium for information.
- Preserve typography ranges and approximate padding as guidance.
- Use the supplied logo files. Do not type, trace, regenerate, recolor, or reconstruct the logo.
- Treat the Blueprint as part of LOFT, not a separate visual identity.
- Do not invent font binaries, photo assets, vector exports, or missing brand rules.
- Distinguish project-specific implementation decisions from the locked brand system.

## Messaging Rules

- Use `MESSAGING_AND_SERVICE_ARCHITECTURE.md` as the authoritative source for current positioning, engagement structure, Blueprint phase names, Stage 05 definition, scope boundaries, preferred terminology, and retired terminology.
- Do not infer services from archived or superseded materials.
- Do not revive Ongoing Partnership, Long-Term Strategic Partnership, Ongoing Financial Operations, mature-practice growth consulting, M&A, succession planning, or multi-location expansion as standard LOFT services.
- Use physician-centered language by default.
- Preserve approved LOFT wording when it remains accurate and strong.
- Do not rewrite copy merely for novelty.
- The word “growth” is not prohibited. Use it only in ways consistent with the current service architecture.
- Never use the phrase “finding its footing.”

## Voice

Keep the voice direct, warm, knowledgeable, measured, and professional.

LOFT should sound like an experienced advisor speaking clearly to another accomplished professional.

Avoid consultant jargon, inflated claims, generic business language, and overly polished phrasing that feels impersonal.

## Review Test

Before finalizing any LOFT work, confirm:

- Does the design feel calm, intelligent, refined, and intentional?
- Does the copy sound like LOFT rather than a generic consulting firm?
- Does the service language match the current engagement architecture?
- Does the work avoid introducing retired or unsupported services?
